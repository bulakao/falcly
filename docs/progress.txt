## Codebase Patterns
- Use `@/` path alias for all imports (maps to project root)
- Expo Router file-based routing: screens in `app/`, modal screens registered in `app/_layout.tsx`
- Zustand stores go in `store/` directory, one store per domain
- Types/interfaces go in `types/` directory
- Decision engine logic in `utils/decisionEngine.ts` — deterministic, first-match-wins evaluation
- Card status uses three channels: color (emerald/amber/crimson) + icon (✓/⚠/✕) + text label
- After adding new route files, Expo regenerates `.expo/types/router.d.ts` — run tsc after to verify
