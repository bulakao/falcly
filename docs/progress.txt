## Codebase Patterns
- SwipeImpactPanel is the main card detail organism — add navigation entry points here using `<Link>` with `asChild` wrapping a `<Pressable>`
- Navigation uses Expo Router `Link` component with `pathname`/`params` pattern for typed routes
- Styles use `useAppTheme()` for colors and `fonts` from `@/theme/fonts` for typography
- Card-specific routes accept `cardId` as a query param via `useLocalSearchParams()`
- Decision engine functions (`calculateCardStatus`, `scoreCard`, `calculateBestCard`) accept optional `currentCycleTxSum` param — defaults to 0 for backward compat
- Per-card callbacks (e.g. `getNetAvailableCash`, `getCurrentCycleTxSum`) are created in HomeScreen and threaded through CardPager to child components
- `EmptyState` component accepts optional `icon` (ReactNode), `title`, `subtitle`, and `children` — use it for all empty states across screens
