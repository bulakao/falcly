# Falcly

Credit card billing cycle intelligence app — "Is it safe to swipe right now?"

## Tech Stack

- **Framework:** Expo CNG (React Native 0.81+, New Architecture enabled)
- **Routing:** Expo Router (file-based, in `app/`)
- **State:** Zustand (persisted via AsyncStorage + Drizzle)
- **Database:** expo-sqlite + Drizzle ORM (local-first, offline)
- **Cloud:** Supabase (Auth + Postgres for cloud sync)
- **Crash reporting:** Custom JS error handler (`utils/crashReporting.ts`)
- **Language:** TypeScript (strict mode)
- **Testing:** Jest + ts-jest
- **Node:** v22 (see `.nvmrc`)

## Project Structure

```
app/            Expo Router screens and layouts
assets/         Fonts, images, splash screen
components/     Reusable React Native components (atoms, molecules, organisms)
constants/      Theme, wiki cards, config values
db/             Drizzle schema definitions
docs/           PRD, discovery notes, design docs
store/          Zustand stores (cards, user, overlay, transactions, etc.)
types/          TypeScript type definitions
utils/          Decision engine, sync, analytics, helpers
__tests__/      Jest test suites
```

## Commands

```bash
npm install          # Install dependencies
npm start            # Start Expo dev server
npm run ios          # Run on iOS simulator
npm run android      # Run on Android emulator
npm test             # Run Jest tests
```

## Conventions

- Path alias: `@/*` maps to project root (e.g., `import { Text } from '@/components/Themed'`)
- CNG workflow: never commit `ios/` or `android/` directories — they are generated by `npx expo prebuild`
- Platform: Android-first, iOS parity at launch
- Decision logic: deterministic engine first, AI augmentation later. "AI can suggest. Only math can decide."
- Tests: Decision engine has full coverage in `__tests__/decisionEngine.test.ts`

## Key Files

- `utils/decisionEngine.ts` — SAFE/CAUTION/RISKY logic, swipe impact, best card
- `utils/statementAdvisor.ts` — Portfolio spread analysis, gap detection, scoring
- `utils/overlayTriggers.ts` — Contextual wiki/tip triggers
- `store/cardStore.ts` — Card CRUD + cloud sync
- `store/overlayStore.ts` — Overlay queue + dismiss logic
